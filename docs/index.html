トークンの作り方
  1. Fine-grained token の作成ページを開く
  2. Repository access で Only select repositories → chiki-chiki/life を選ぶ
  3. Permissions の Repository permissions で Issues を Read and write にする
  4. Generate token で作成し、表示されたトークンを上に貼り付ける

トークンはこの端末のブラウザの中にだけ保存され、GitHub API との通信にだけ使います。
